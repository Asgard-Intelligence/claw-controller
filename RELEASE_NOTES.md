# v1.4.0 Release Notes

## Overview
v1.4.0 introduces a hybrid orchestration architecture with route-level execution, adapter-based provider runtime, and separate validation and health services.

## Highlights
- Hybrid route execution model
- Adapter-based execution engine
- Dedicated validation service
- Dedicated health service
- Lossless session persistence
- Backward compatibility with v1.3 session migration

## Operational Improvements
- Cleaner separation between API orchestration and execution
- Better provider abstraction via contracts and adapters
- Safer request and response normalization flow
- Improved test coverage for session, routing, validation, and backward compatibility
